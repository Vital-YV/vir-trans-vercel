# Manrope

Unmodified variable TrueType font from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/manrope

Source filename: `Manrope[wght].ttf`.
Stored filename: `Manrope-Variable.ttf` (file contents unchanged).
Downloaded: 2026-10-14.
Verified Git blob SHA-1: `75274da58537d6123b14f2cd0c355ad4681fc2b3`.

Weight axis: 200–800, normal style. Includes Cyrillic and Latin glyphs.
The original copyright notice and SIL Open Font License 1.1 are included in `OFL.txt`.

`app/layout.tsx` uses `next/font/local`, preserving `--font-manrope` and `display: swap`.
Builds and browser font loads use the bundled file; Google Fonts is not contacted.
